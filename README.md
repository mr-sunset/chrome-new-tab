## Design
This extension features 3 main elements:
1. A colorful Google theme heading
2. 6 links to Google services
   - YouTube
   - Gmail
   - Gemini
   - Docs
   - Slides
   - Sheets 
4. A quick search box

It is also dark mode and mobile-friendly.

## I want to use this!
Since this extension isn't on the Chrome Web Store, you'll have to use your browser's "Load Unpacked" (Chromium only) feature.
1. Go to the latest release and download the ZIP.
2. Extract the folder.
3. Go to your browser's extension page.
4. Turn on developer options and click "Load Unpacked".
5. Select the folder.
